# Repository instructions

- Keep mobile, web, and API code inside their respective `apps/*` directories.
- Read the nearest nested `AGENTS.md` before changing an app.
- Use TypeScript for product code and keep API contracts explicit and versioned.
- Never commit `.env` files, service-account JSON, Recovery IDs, or session tokens.
- Preserve client source references on the archive branch; do not copy them back to `main`.
